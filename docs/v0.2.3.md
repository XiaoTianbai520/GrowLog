# 0.2.3 · Markdown 原位编辑与界面质感优化

0.2.3 将笔记编辑改为 Markdown 原位编辑：当前内容保留源码，离开后直接在同一区域显示排版结果。同时补齐长笔记滚动、预览间距与键盘导航，并扩展界面的毛玻璃层次。

## Markdown 原位编辑

- 笔记模式调整为「原位编辑 / 源码 / 阅读」，默认使用原位编辑。
- 当前行、列表项或完整代码块显示源码，其余内容在同一区域直接预览；点击或用方向键移入即可继续编辑。
- 支持标题、强调、删除线、引用、列表、任务列表、链接、图片、代码块、分隔线和 GFM 表格。
- 列表回车自动续项，空列表项回车退出；代码块内正常换行，中文输入法确认候选词不会误触发转换。
- 保留自动保存、撤销重做、图片粘贴与拖拽、Markdown 导入导出及思维导图标题跳转。

## 编辑体验修复

- 长笔记与长表格按实际预览高度计算滚动范围，可稳定滚动到文档末尾。
- 收紧原位预览的行间距，消除预览块边界产生的多余空行。
- 修复方向键跨越预览块时无法恢复源码的问题。

## 界面优化

- 文件夹栏、笔记列表、文档操作栏与 Markdown 工具栏使用灰蓝色毛玻璃边框。
- 导航栏、顶部栏、成就卡片、弹窗与提示区域增加统一的玻璃层次。
- 浅色、深色与不支持背景模糊的系统均保留清晰的选中、悬停和键盘焦点状态。

## 兼容与升级

0.2.3 不修改数据库结构，与 0.2.2 共用 V2 数据格式。覆盖安装会保留笔记、文件夹、图片、经验和成就。安装前仍建议在设置中导出一份完整备份。
