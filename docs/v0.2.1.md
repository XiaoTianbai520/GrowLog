# 0.2.1 · 文件夹思维导图

0.2.1 在原有 Markdown 笔记上增加零配置的思维导图视图。它不创建额外数据，也不需要手动维护：文件夹是根节点，笔记是主分支，Markdown `#` 至 `######` 标题按层级自动成为子分支。

## 新增

- 选中文件夹后，可在「列表 / 导图」之间切换。
- 导图只显示文件夹、笔记名和 Markdown 标题，不显示正文。
- 点击笔记节点打开文首；点击标题节点定位并短暂高亮原文标题。
- 编辑、分栏和阅读模式均支持定位。
- 标题变更后自动更新，当前未落盘的草稿也会反映到导图。
- 文件夹、笔记和标题节点都可自由拖动，连线会实时跟随。
- 手动布局按文件夹保存在本机，重启应用后仍会恢复；也可一键回到自动布局。
- 忽略 Markdown 代码块内的伪标题。

## 兼容与升级

0.2.1 不修改数据库结构，与 0.2.0 共用 V2 数据格式。覆盖安装不会删除笔记、文件夹、图片、经验或成就。安装前仍建议在设置中导出一份完整备份。
