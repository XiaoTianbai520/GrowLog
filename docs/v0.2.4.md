# 0.2.4 · Typora 风格笔记快捷键

0.2.4 为笔记的所见即所得和 Markdown 源码两种编辑模式增加了 Typora for Windows/Linux 风格的快捷键，并在编辑工具上显示对应的快捷键提示。

## 主要变化

- `Ctrl+0` 切换为正文，`Ctrl+1`–`Ctrl+6` 切换为一至六级标题。
- 支持粗体、斜体、删除线、行内代码、链接和清除格式等 Typora 快捷键。
- 支持表格、代码块、公式块、引用、有序列表、无序列表和图片等块级快捷键。
- 鼠标悬停在编辑按钮和标题选项上时，显示操作名称与快捷键。
- 笔记编辑区内的 `Ctrl+K` 优先创建链接，不会误打开全局搜索。

## 数据兼容性

0.2.4 不修改数据库结构，与 0.2.3 共用 V2 数据格式。覆盖安装会保留笔记、文件夹、图片、经验和成就。
