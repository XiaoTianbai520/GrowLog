# 0.2.0 · 每日任务与等级

在原有 Markdown 笔记、成就与备份基础上，增加独立的「每日任务」栏目。工作台和侧栏同步显示等级；完成任务后显示经验到账提示，达到门槛时显示升级提示。

## 使用规则

| 项目 | 规则 |
| --- | --- |
| 每日签到 | 点击签到，+10 经验 |
| 每日记笔记 | 当天新写或修改非空笔记正文并成功保存，自动 +30 经验 |
| 每日上限 | 每项每天一次，共 40 经验 |
| 等级 | 从 Lv. 1 开始，每 100 经验升一级，不扣除累计经验 |
| 日期 | 电脑本地日期；跨日后任务重新开放 |
| 不计入的操作 | 空笔记、只改标题/标签/收藏、仅改首尾空白、重复保存、回收站恢复 |
| 不扣除 | 漏签、删除笔记、撤销其他成就，不扣经验 |
| 记录 | 页面显示最近 30 次奖励，累计经验计算全部历史 |

固定任务的奖励与等级规则在 Rust `growth.rs` 中定义。当前没有自定义每日任务、补签或改经验按钮；现有自定义成就不受影响。完全本地运行，日期可信度取决于电脑时钟，不建立联网防作弊服务。

## 升级与备份

先保存并退出旧版，再运行 `release/枝序-0.2.0-Setup.exe`。安装目录与用户数据分离。首次打开新版时，先创建迁移前备份，再将数据库从版本 1 升级至版本 2，原有笔记与成就保留，经验从零开始。

新版 `.zhixu` 包含经验流水和每日完成日期。恢复会整体回到备份状态，不做合并；恢复 V1 备份时，笔记与成就正常迁移，但因为旧版没有经验记录，经验为零。恢复前仍会备份当前数据。已经升级的数据库不能用旧版程序打开。
