# 0.2.2 · Markdown 导入导出与图片拖拽插入

0.2.2 让笔记与外部 Markdown 文件、本地图片双向打通：可以把 `.md` 文件导入成新笔记、把笔记导出回 `.md` 文件，也可以把图片拖到编辑器的任意位置插入。

## 新增

### Markdown 导入导出

- 笔记列表标题栏新增「导入 Markdown」按钮，选择本地 `.md` / `.markdown` 文件后新建一篇笔记。
- 也可以直接把 `.md` 文件从资源管理器拖进应用窗口任意位置，松手即导入。
- 导入统一新建一篇笔记：文件名（去扩展名）作为标题，文件内容作为正文；导入超过 5MB 的文件会被拒绝。
- 选中笔记后，「文档操作」区新增「导出为 Markdown 文件」按钮，仅导出正文；保存对话框默认以笔记标题命名文件。
- 回收站中的笔记不能导出。

### 图片拖拽插入

- 把图片文件拖到编辑器（源码模式）里，鼠标松开的位置就是图片插入的位置。
- 编辑器内先插入占位符 `![图片](growlog-uploading-…)` 锁定位置，后台导入完成后原位替换为真实附件路径；期间继续打字也不会漂移。
- 若占位符在导入完成前被删除，会提示「图片已导入，但插入位置已被删除」，图片本身仍在附件库中。
- 图片与粘贴上传共用同一存储链路，仍保存在本地数据目录，预览仅显示本地图。
- 拖拽悬停时编辑区与列表区分别显示虚线高亮，提示当前松手会发生什么。

## 兼容与升级

0.2.2 不修改数据库结构，与 0.2.0 / 0.2.1 共用 V2 数据格式。覆盖安装不会删除笔记、文件夹、图片、经验或成就。安装前仍建议在设置中导出一份完整备份。

## 已知局限

- 从外部导入的 Markdown 中如引用了本地图片路径，图片不会自动带入应用（预览仅显示应用内附件，属于现有安全设计）。
- 导出的 `.md` 只含正文文本；笔记的标签、收藏状态等元数据不写入文件。
